# 📝 TIPS PARA USAR EL CUADERNO

1. **Usar lapicero** para acuerdos/decisiones (no se borra)
2. **Usar lápiz** para estados que cambian
3. **Firmar** acuerdos importantes (conecta con el cerebro)
4. **Fecha** en todo — siempre
5. **Referencia cruzada** — anotar número de página cuando algo se relaciona
6. **No arrancar hojas** — tachar con una línea si algo cambia

## 🏷️ Sistema de Símbolos Rápidos

```
□  = Tarea pendiente
☑  = Tarea completada
→  = Movido/delegado
✗  = Cancelado
!  = Urgente
?  = Necesita decisión
★  = Importante
⚠  = Bloqueador
```
