## 💵 Precios de Servicios

### Cursos y Capacitaciones

| Tipo de Cliente | Precio | Notas |
|-----------------|--------|-------|
| **Empresas** | Precio completo | Cotización según alcance |
| **Instituciones educativas** | Reducido + publicidad | Negociar visibilidad |
| **Escuelas nacionales** | Contribución voluntaria | Mínimo Gs. 5,000 por persona |
| **Gratuito** | ❌ NO | "Lo gratis no se valora" |

### Por qué no gratis

> "Lo que se da gratis, no se valora. Si es gratis, no tiene valor."

Incluso una contribución mínima genera:
- Compromiso del participante
- Percepción de valor
- Respeto por el trabajo

## 📝 Contratos

### Regla de Oro

```
NO TRABAJO SIN CONTRATO
```

### Elementos Mínimos de un Contrato

- [ ] Partes involucradas (nombres completos, CI)
- [ ] Descripción del trabajo/servicio
- [ ] Entregables específicos
- [ ] Fechas y plazos
- [ ] Precio y forma de pago
- [ ] Responsabilidades de cada parte
- [ ] Qué pasa si algo sale mal
- [ ] Firmas de todas las partes

## 💡 Consejos Financieros

### Valorar tu Trabajo

> "El trabajo puede ser hermoso, bien hecho, pero si no se muestra, no vale nada."

- El trabajo de organización y ventas tiene valor de mercado
- Preguntar a IA: ¿Cuánto cobra un CEO por hora? ¿Cuánto alguien que vende?
- No dejar que otros definan tu valor — tú lo defines

### Negociación

| ✅ Hacer | ❌ No hacer |
|----------|-------------|
| Investigar precios de mercado | Improvisar números |
| Tener rangos preparados | Dar precio sin pensar |
| Documentar acuerdos | Confiar en palabra |
| Pedir anticipo | Trabajar sin garantía |

## 📋 Checklist Antes de Cerrar un Trato

- [ ] ¿Está claro qué se entrega?
- [ ] ¿Está claro el precio?
- [ ] ¿Está claro cuándo se paga?
- [ ] ¿Hay contrato firmado?
- [ ] ¿Se definió qué pasa si algo sale mal?
- [ ] ¿Todos los involucrados están de acuerdo?
- [ ] ¿Está documentado en el Drive?
