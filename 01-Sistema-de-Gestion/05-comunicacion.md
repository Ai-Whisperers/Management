## 📜 Reglas de Comunicación

### ✅ LO QUE SÍ

| Regla | Explicación |
|-------|-------------|
| **Responder en 24h** | Aunque sea "lo veo y te confirmo" |
| **Ser claro y directo** | No asumir que el otro entiende |
| **Documentar acuerdos** | Si se acordó algo, escribirlo |
| **Usar el canal correcto** | No mezclar canales |
| **Confirmar recepción** | "Recibido" o "Entendido" |

### ❌ LO QUE NO

| Evitar | Por qué |
|--------|---------|
| Cambiar de canal constantemente | Genera confusión |
| Dejar mensajes sin responder | Crea incertidumbre |
| Asumir que el otro entendió | Siempre confirmar |
| Hablar de trabajo en canales personales | Mantener límites |
| Ignorar mensajes urgentes | Responder aunque sea breve |

## 🗣️ Comunicación con Iván (Importante)

### Contexto
- Iván es Gemini — ritmo mental rápido
- Cambia de idea frecuentemente (es su naturaleza, no maldad)
- Se cierra si le hablan en tono de queja
- Necesita expresar ideas verbalmente

### Estrategia de Comunicación

| Situación | ❌ No hacer | ✅ Hacer |
|-----------|-------------|----------|
| Pedir algo | Exigir con urgencia | "¿Podemos hablar de X?" |
| Desacuerdo | Subir el tono | Traer datos, hablar calmado |
| Feedback | Criticar directamente | "Desde mi rol, necesito..." |
| Decisión importante | Presionar en el momento | Preparar análisis previo |

### Frases Útiles

```
✅ "¿Podemos agendar para hablar de esto?"
✅ "Desde mi rol de organización, necesito..."
✅ "Tengo estos datos, ¿qué opinas?"
✅ "Entiendo tu punto, y también..."
✅ "¿Cómo lo ves tú?"

❌ "Siempre haces lo mismo"
❌ "No me escuchas"
❌ "Esto es obvio"
❌ "Ya te lo dije"
```

## 🚨 Comunicación de Emergencias

### ¿Qué es emergencia?

| ✅ Emergencia | ❌ No es emergencia |
|---------------|---------------------|
| Sistema caído con cliente afectado | Bug menor |
| Deadline en las próximas 24h | Tarea pendiente |
| Problema de seguridad | Feature request |
| Cliente muy enojado | Pregunta general |

### Protocolo de Emergencia

1. Escribir en canal de emergencias
2. Describir el problema claramente
3. Indicar urgencia y deadline
4. Esperar máximo 1 hora respuesta
5. Si no hay respuesta, llamar

## 📝 Documentación de Comunicaciones

### Qué documentar

| Siempre documentar | No necesario documentar |
|--------------------|-------------------------|
| Acuerdos y decisiones | Conversaciones casuales |
| Cambios de plan | Preguntas rápidas |
| Compromisos con fechas | Saludos y check-ins |
| Feedback importante | Coordinación simple |

### Dónde documentar

```
Acuerdos importantes → Drive + Cuaderno físico
Decisiones de reunión → Acta de reunión
Cambios de proyecto → GitHub issues / Drive
Comunicación con clientes → Carpeta del cliente
```

## 🤝 Resolución de Conflictos

### Proceso

```
1. PAUSA
   - Si hay tensión, pedir 5 minutos
   - Respirar, no reaccionar en caliente

2. HABLAR DESDE EL ROL
   - "Como responsable de X, necesito..."
   - No "tú siempre..." o "tú nunca..."

3. TRAER DATOS
   - Evidencia objetiva
   - No opiniones o suposiciones

4. BUSCAR SOLUCIÓN
   - ¿Qué podemos hacer diferente?
   - ¿Cómo evitamos esto en el futuro?

5. DOCUMENTAR
   - Escribir el acuerdo
   - Firmar si es importante
```

### Si no se resuelve

- Agendar reunión específica para el tema
- Si persiste, considerar mediador externo
- Siempre mantener respeto profesional
