## 🎯 Cómo Usar Esta Documentación

### Para nuevos miembros:
1. Leer **01-Reglas de Oro** primero
2. Revisar **02-Roles** para entender su posición
3. Estudiar **03-Procesos de Reunión**

### Para reuniones:
- Revisar **03-Procesos de Reunión** antes del meeting
- Usar la plantilla de agenda

### Para proyectos nuevos:
- Seguir **04-Gestión de Proyectos**
- Asignar responsables según **02-Roles**

### Para temas de dinero:
- Consultar **06-Finanzas y Contratos**
- Nunca acordar nada sin documento escrito
